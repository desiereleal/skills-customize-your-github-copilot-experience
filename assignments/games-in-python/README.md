
# 📘 Assignment: Jogo da Forca

## 🎯 Objective

Construir um jogo da Forca em Python para praticar manipulação de strings, loops e condicionais. Ao final, o aluno deverá implementar o fluxo completo do jogo com seleção aleatória de palavras e controle de tentativas.

## 📝 Tasks

### 🛠️ Implementar o jogo da Forca

#### Descrição
Crie um programa em Python que selecione uma palavra aleatória de uma lista predefinida e permita que o jogador tente adivinhar a palavra letra por letra.

#### Requisitos
O programa concluído deve:

- Selecionar palavras aleatoriamente de uma lista predefinida.
- Aceitar palpites de letras e mostrar o progresso atual no formato _ _ _.
- Rastrear tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou quando as tentativas se esgotarem.
- Exibir mensagens finais de vitória ou derrota.
